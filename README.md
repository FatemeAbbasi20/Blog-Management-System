Blog Management System

A full-featured blog platform built with ASP.NET Core MVC, C#, and Razor, featuring a dynamic public website and a comprehensive admin dashboard.

Key Features

• Admin Dashboard: Complete content management system.
• Blog Management: Create, edit, delete, and manage articles.
• Category Management: Dynamic categories and nested subcategories.
• Authentication & Authorization: User authentication, Role-Based and Policy-Based authorization.
• Comment Management: Manage and moderate user comments.
• AJAX Search & Pagination: Dynamic content filtering and asynchronous interactions.
• Rich Text Editor: CKEditor integration for article content.
• Image Upload: Article image management and file validation.
• SEO: Dynamic metadata, SEO-friendly URLs, and slug generation.
• Error Handling: Custom error pages and centralized exception handling.
• Localization: Persian date conversion and localized content.

Tech Stack

Backend: C#, ASP.NET Core MVC, Razor

Frontend: HTML5, CSS3, JavaScript, jQuery, Bootstrap, AJAX

Tools & Libraries: CKEditor, SweetAlert
